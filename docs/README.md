# Документация

Это подробный разбор того, как устроен помидоро-трекер: из чего он собран, почему
собран именно так и где что искать. Корневой [README](../README.md) отвечает на вопрос
«что это и как запустить», здесь — «как оно работает внутри».

## С чего начать

Если открыл проект впервые, читай по порядку — каждая следующая часть опирается
на предыдущую:

1. **[Архитектура](01-architecture.md)** — слои, правила зависимостей, как приложение
   собирается при запуске и как данные доходят до экрана. Самая важная часть.
2. **[Домен](02-domain.md)** — таймер, сутки, периоды, типы работы. Чистая логика,
   в которой нет ни базы, ни интерфейса.
3. **[Хранилище](03-storage.md)** — SQLite: схема, запросы, миграции, настройки, консоль.
4. **[Статистика](04-statistics.md)** — как из списка записей получаются итоги,
   диаграмма и медиана.
5. **[Интерфейс](05-ui.md)** — MVVM: модели представления, экраны, привязки, стили.
6. **[Тесты](06-testing.md)** — что проверено, как устроены подделки и как дописать своё.
7. **[Сборка и выпуск](07-build.md)** — конфигурации, анализаторы, публикация, CI.
8. **[Журнал решений](08-decisions.md)** — почему сделано так, а не иначе, и что было
   отвергнуто. Читать, когда непонятно «зачем здесь этот костыль».
9. **[Рецепты](09-recipes.md)** — пошагово: добавить настройку, период, колонку, поле.
10. **[Языки](10-localization.md)** — русский и английский: где строки, как переключается.

Если нужно быстро понять устройство — хватит четырёх файлов кода:
`App.xaml.cs` → `Domain/PomodoroTimer.cs` → `ViewModels/MainViewModel.cs` →
`Stats/StatsCalculator.cs`.

## Карта проекта

```
Pomidoro/
├─ App.xaml, App.xaml.cs      точка входа и сборка приложения
├─ Domain/                    таймер, сутки, периоды, типы — без WPF и без базы
├─ Stats/                     счёт статистики и геометрия диаграммы — чистые функции
├─ Storage/                   SQLite, настройки, консоль разработчика
├─ Formatting/                числа и даты → текст на экране
├─ Localization/              русский и английский текст интерфейса
├─ Mvvm/                      уведомления, команды, источник тиков
├─ ViewModels/                состояние экранов и команды кнопок
├─ Views/                     разметка окон и экранов
├─ Themes/                    цвета и стили
├─ Audio/                     сигнал конца фазы
├─ Tray/                      значок в области уведомлений
├─ tests/Pomidoro.Tests/      162 теста
└─ docs/                      этот каталог
```

## Соглашения, принятые в коде

- **Всё внутреннее.** Типы объявлены `internal`: это приложение, а не библиотека.
  Тесты видят их через `InternalsVisibleTo` в `Pomidoro.csproj`.
- **Явные типы вместо `var`.** Код читают чаще, чем пишут.
- **Один тип — один файл**, имя файла совпадает с именем типа.
- **XML-документации нет.** Объяснения живут здесь и в коротких комментариях
  там, где поведение неочевидно; имена при этом должны говорить сами за себя.
- **Комментарий отвечает на «почему», а не на «что».** Если комментарий пересказывает
  код — он лишний.
- **Порядок членов в классе:** константы, поля, конструктор, события, свойства,
  публичные методы, приватные методы.
- **Кодировка:** UTF-8 без BOM, переводы строк CRLF, отступ — четыре пробела.
- **Предупреждения компилятора и анализаторов — ошибки сборки.**
